# Contributing

- Read `docs/architecture/README.md` before adding a skill, rule, or adapter.
- Add `Signed-off-by:` to commits (Developer Certificate of Origin).
- Do not put statutes or standards text in CC0 paths.
- Do not set a review state on an obligation. Review state is computed.
- Run `pnpm test` and `pnpm --filter @readyvibe/skill-lint start -- .` before opening a pull request.
- Skill names, once published, stay. Deprecate instead of renaming.
