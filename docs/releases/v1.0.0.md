# ReadyVibe-Skills v1.0.0

ReadyVibe-Skills helps coding agents turn polished-looking web projects into responsibly launchable products: they inspect what the project actually does, fix safe issues, verify each change, and identify what requires a human.

## Install

```bash
npx skills add moh-obaida/ReadyVibe-Skills#v1.0.0 --skill launch-all
```

Then ask your agent: **"Make this ready to launch."**

`--skill launch-all` installs one skill that *considers* 40 launch checks and activates only the ones that apply. `--all` installs every skill. To pin any install to this release, add `#v1.0.0` to the repository name. No ReadyVibe CLI, package, account, or service is required.

## What's in it

- **55 skills** in nine categories, each with a real operating method: when to activate, what to inspect, what evidence counts, what it may change, what it must not claim, how to verify, when to escalate, and when doing nothing is correct.
- **`launch-all`**: considers 40 launch checks and 12 conditional compliance domains, routes only to the lanes that apply, verifies fixes, and reports READY / FIXED / BLOCKERS / REVIEW REQUIRED / UNVERIFIED / NEXT ACTION.
- **`compliance-all`**: privacy, consent, marketing email, age, rights, commerce, vendors, and regulated-domain triggers, separating technical fact from legal requirement from applicability. It never says "compliant".
- **`admin-dashboard`**: builds or improves a full admin tailored to *your* product, in *your* design system, from your real data model, with server-side authorization and no invented metrics.
- **SEO, social sharing, structured data, and search-console readiness** that check how canonicals, sitemap, robots, and noindex agree, not just whether files exist.
- **Accessibility, mobile, forms, error pages, links, performance, FAQ, and trust** skills that exercise the real site.
- **Privacy and consent** skills that verify reject, accept, and withdraw at runtime; trace unsubscribe and deletion through stored state; and compare disclosures with observed behavior.
- **Production and security**: secrets, deployment leftovers, headers, dependencies, payments, subscriptions, and admin authorization.
- **Internationalization**: multilingual and right-to-left readiness.
- **Standalone by design**: every skill carries its own helpers and references. Where it relies on another skill's method it declares that skill as a companion and carries a reduced-depth fallback, reporting when a lane ran that way.
- **Your design, not ours**: anything visible follows your existing design system.

## What it does not promise

It is not a lawyer, a WCAG conformance audit, a penetration test, or a guarantee that a search engine will index a page. It does not claim legal compliance, accessibility conformance, or security certification. Legal specifics are looked up at official sources and cited, and unresolved facts are marked for human review. Automated checks cover the helpers, the lint, and installation; how a given agent behaves with the skills is not automatically tested.
