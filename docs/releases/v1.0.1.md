# ReadyVibe-Skills v1.0.1

**Free marketplace distribution update.** ReadyVibe remains the same Apache-2.0, open-source collection of 55 production and launch-readiness skills, with additional ways to package and install it.

## Highlights

- **Unified marketplace bundle:** `ReadyVibe-Skills.zip` contains one `readyvibe-skills/SKILL.md` master router and all 55 public methods in `modules/<category>/<name>/METHOD.md`. It selects only applicable specialists rather than loading all 55 every time.
- **Individual marketplace archives:** `pnpm marketplace:build` creates a standalone ZIP for each public skill, including its vendored helpers, references, and license. `pnpm marketplace:skill --skill wcag-readiness` builds a selected skill.
- **Reproducible, checked packaging:** The unified bundle includes a generated catalog, routing guide, and SHA-256 manifest, with tests for archive layout, routes, relative references, imports, helper execution, isolation, and deterministic bytes.
- **Unchanged Skills CLI installs:** The 55 canonical skill folders and standard GitHub installation paths remain intact.

## Install individual skills

```bash
npx skills add moh-obaida/ReadyVibe-Skills#v1.0.1 --skill launch-all
```

Or install the complete existing collection via the Skills CLI:

```bash
npx skills add moh-obaida/ReadyVibe-Skills#v1.0.1 --all
```

## Unified bundle

Download the attached `ReadyVibe-Skills.zip` from this release. It is a single self-contained ReadyVibe skill bundle: one master entry point routes to all 55 bundled methods. Extract the top-level `readyvibe-skills/` folder into your coding agent's supported skills directory. For the Agensi marketplace, submit **this ZIP**, not the automatically downloaded GitHub source archive.

The bundle was mechanically tested with Skills CLI discovery and installation into Claude Code's skill layout. A model-driven agent evaluation and Agensi's own approval are separate verification steps; this GitHub release does not imply marketplace publication.

You can rebuild the archive from source:

```bash
pnpm install --frozen-lockfile
pnpm marketplace:bundle
```
