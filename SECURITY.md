# Security policy

Report vulnerabilities in the ReadyVibe engine, skill-lint, or artifact handling through a private GitHub security advisory. Do not open a public issue for an unfixed vulnerability.

In scope: artifact path escapes, secret redaction failures, status authority bypasses, and skill-lint misses that would publish a hidden skill.

ReadyVibe treats inspected repositories as untrusted. It does not run their install scripts. Out of scope: vulnerabilities in a website you point ReadyVibe at.
